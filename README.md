# AI-Powered Multi-Agent Travel Planner ✈️

## Project Overview

An intelligent travel planning application that uses a Multi-Agent AI architecture to generate personalized travel itineraries based on user preferences.

The application allows users to specify their destination, interests, travel style, trip duration, and budget to receive customized travel recommendations.

## Domain
Artificial Intelligence and Data Science

## Subdomain
Generative AI, Agentic AI and Multi-Agent Systems.

## Technologies Used
- Python
- LangChain
- LangGraph
- Groq LLM
- Gradio

## Features
- Personalized travel itinerary generation
- User interest-based recommendations
- Travel style customization
- Budget-based trip planning
- Interactive Gradio web interface
- Multi-Agent AI workflow

## Project Structure

- `AI_Travel_Planner.ipynb` – Main project notebook
- `requirements.txt` – Python dependencies
- `README.md` – Project documentation

## Installation

Install dependencies:

```bash
pip install -r requirements.txt
```

Configure your Groq API key as an environment secret before running the application.

## Execution

Open the notebook in Google Colab, configure your API key, execute the cells, and launch the Gradio interface.
